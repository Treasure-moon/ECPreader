<h1 align="center">ECPreader</h1>

<p align="center">本地运行的论文双语对照阅读器</p>

把 PDF / Word 论文拖进窗口：左侧保留论文原貌，右侧在同一位置显示中文译文；也可以切换逐句对照，选中句子两边同步高亮，双击单词查看词典释义和语境意译，顺手把「这个意思」收进生词本。配置好自己的 AI 接口后，右下角的 ✦ 按钮还能唤起阅读助手，它读过当前这篇论文。

文档、译文、历史和 API Key 都只保存在本机。只有待翻译的句子会发送到你选择的翻译服务；阅读助手只会把问题和论文正文发送到你填写的 AI 接口。

## 功能

- **两层顶栏**：上层全局栏放标签页与引擎、设置入口，下层阅读栏放翻译、视图、缩放与查找，互不挤占。
- **多标签页**：同时打开、翻译、阅读多篇论文，每篇论文的状态互不影响。
- **全屏阅读**：隐藏顶栏与侧栏专注读正文，`Esc` 退出，左侧可随时唤出目录；右下角的 ✦ 阅读助手在全屏里同样可用。
- **PDF / Word**：支持文本型 PDF 和 `.docx`，保留标题、段落、图表说明、公式和参考文献结构。
- **原版对照**：整页按原样渲染，中文按原坐标覆盖，公式、图片、双栏排版不会被拆乱。
- **逐句对照**：正文重排成左右两栏，共享滚动位置，适合精读。
- **划选联动**：在任一栏选中句子，另一栏同步高亮；双击单词就地查词。
- **文档内查找**：`Ctrl+F` 精确查找原文或译文，只高亮匹配字符，可上下跳转。
- **生词本**：双击单词后，浮层右上角的 ☆ 收藏的不是单词本身，而是「这个语境里的这个意思」——同一个词在不同论文里意思不同，就分开记，各自带着来源论文与页码。按钮会变成圈里的 ✓（这个意思已收藏）或圈里一个数字（这个词已收藏 N 个意思，鼠标放上去显示 +1），再点一次取消收藏。顶栏「翻译设置」和「关于」之间的书本图标就是入口，分单词、分类、时间、文章四种方式查看：收藏过的意思加粗显示，后面跟着它的语境示意，没收藏的常见义项排在下面；鼠标放到加粗的意思上显示来源论文、页码和收藏时间（文章已删除则显示「文章丢失」），点单词进单词详情。在「文章」视图里，每篇文章旁边有「打开文章」按钮（只打开这篇论文，不定位段落），在「分类」视图里把单词拖到别的分类下面就能改分类（空分类也会列出来当投放处），「文章」视图里把文章标题或单条收藏拖到列表上方的分类上，也能改整篇或单条。可导出 CSV（Excel 直接打开）或 Markdown。
- **AI 阅读助手**：配置 AI 接口后，右下角 ✦ 打开悬浮窗对话。它读你正在看的论文，能总结、拆解方法、找局限、解释名词，也了解 ECPreader 自身的使用方式（功能、快捷键、版本差异、反馈邮箱），发现有新版本会提示更新；全屏阅读里同样可用，对话只留在内存里，不会写进历史。
- **读多少由你决定**：默认只把论文前约 2.4 万字符（通常前几页）发给 AI，加上全文目录和你正在看的那一页；面板顶部会写明「只包含到第几页」。要整篇总结，可在「翻译设置 → AI 引擎」把「阅读助手上下文上限」调大，或打开「总结全文时发送整篇」（默认关闭）——上限越大，输入 token 与费用大致同比例增加。
- **两种引擎**：免费机翻（MyMemory / Google / Bing），或 OpenAI 兼容的 AI 接口（DeepSeek、OpenAI、硅基流动、Ollama 等）。
- **术语一致**：可维护术语表，AI 模式会结合上下文统一译法。
- **可控成本**：按段分批翻译，失败可补译，单段可重译。
- **导出**：Markdown 对照、双语 HTML、JSON、纯英文 TXT。
- **本地历史**：SQLite 记录每次翻译，可搜索、导出、清空。
- **数据加密**：API Key 使用 Windows DPAPI + AES-256-GCM 加密保存。

## 使用

1. 安装并启动 ECPreader。
2. 把 PDF 或 `.docx` 拖进窗口，或者点「选择文件」。
3. 选择翻译引擎，点「翻译全文」。
4. 左侧看原文，右侧看译文；选中句子会同步定位，双击单词可查词，浮层右上角的 ☆ 把这个意思收进生词本（顶栏书本图标里查看、分类与导出）。
5. 想同时读几篇，点顶栏 `＋` 或直接再拖入文件；点标签切换，`Alt+W` 关掉当前标签。
6. 点阅读栏 `⛶` 进入全屏阅读，`Esc` 退出；鼠标移到屏幕左边缘可唤出目录。
7. 已配置 AI 接口时，点右下角 ✦ 打开阅读助手，可以直接问这篇论文的任何问题；全屏阅读时它也能用，`Esc` 先关助手、再按一次退出全屏。

免费机翻开箱即用。使用 AI 翻译前，在「翻译设置」里填写接口地址、模型和 API Key；同一个接口也会成为阅读助手使用的接口。

数据目录可以在安装时选择，也可以随时在「翻译设置 → 数据与安全」中更改并迁移。

## 从源码运行

需要 Python 3.10 或更高版本（开发使用 3.12）：

```text
start.bat
```

首次运行会自动创建虚拟环境并安装依赖，之后直接启动桌面窗口。

## 打包

```text
build_exe.bat
```

生成 `dist\ECPReader.exe`（免安装单文件版）。

```text
build_installer.bat
```

生成 `installer\dist\ECPreader-Setup-1.6.0.exe`（安装包，内含卸载程序）。

发布新版本时：先把 `RELEASES.md` 里新版本标题上的「（开发版）」去掉，再改 `APP_VERSION`
（`app/config.py`、`app/__init__.py`、`installer/setup_app.py`、`tools/ecp_version.txt`、`build_installer.bat`），
然后写 GitHub Releases。

## 数据与隐私

- 论文只在本机解析；只有被翻译的句子会发送到所选翻译服务。
- 阅读助手只用你填写的 AI 接口：发送内容是「你的提问 + 当前论文正文（数量由上面的上下文上限决定）+ 固定的助手设定」。论文很长时只发前面一部分（面板会写明包含到第几页），另外带上论文目录和你正在看的那一页，方便你就地追问。你填写的 API Key、邮箱等设置不会进入对话请求。
- 阅读助手的对话只保存在内存里，关掉窗口或切换标签即清空，不写数据库、不进历史记录。
- 打开阅读助手时会向项目仓库查询一次最新版本号（只发一个 GET，不带任何本机信息，结果缓存 6 小时），好让旧版本里的助手也能提醒你更新；不需要可以在「翻译设置 → 数据与安全」关掉。
- 默认数据目录：安装版为安装时选择的目录，源码版为项目下的 `data\`。
- 数据目录包含 `app.db`（文档、译文、历史、生词本）、`vault.*`（加密凭据）、`uploads/`、`pages/`。
- 生词本里的词义、分类、来源论文与页码只写在本机 `app.db`；只有你点「导出 CSV / Markdown」时才生成文件，导出内容不会上传。
- `vault.key` 由 Windows DPAPI 绑定当前账户，换账户或换电脑后需要重新填写 API Key。
- 项目不包含埋点、遥测或云端同步。
- 仓库和安装包不包含任何 API Key、文档或历史记录，首次启动是空白状态。
