ECPreader
本地运行 · 数据不出电脑

把论文拖进来，
左边英文，右边中文

支持 PDF 与 Word(.docx)，保留标题、段落、图表说明、公式与参考文献结构；
选中任意一句，另一栏同步定位；选中单词，立即查看释义与语境意译。

⇪
把 PDF 或 .docx 拖到这里
或者 · 单文件不超过 100MB

⇄

段落级双向对齐

以句子为最小对齐单元，左右两栏共享同一滚动轴，原文与译文始终同行。

◎

选中即对照

在任一栏选中内容，另一栏对应句子即时高亮；选中后可用顶部 ↻ 单独重译。

“”

单词释义

选中单个英文单词，查看音标、词典释义、当前语境义与整句意译。

⧉

多标签页

像浏览器一样同时打开多篇论文，各自独立翻译、独立滚动，互不打断。

⛶

全屏阅读

隐藏所有界面元素专注阅读，Esc 退出；左侧可随时唤出目录，Ctrl+F 照常查找。

⛨

凭据本地加密

API Key 使用 Windows DPAPI + AES-256-GCM 加密，永不落明文、永不上传。

更改后会把现有数据一起迁移到新目录，重启软件生效。

所有文档、译文、术语表与历史记录都保存在本机数据目录的 SQLite 数据库中； API Key 单独加密存放在 vault.bin，主密钥由 Windows DPAPI 绑定当前账户，换账户或换电脑都无法解密。 程序不包含任何埋点、遥测或云端同步。

修改后请点击「保存设置」
